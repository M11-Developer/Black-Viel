# BLACK VEIL — DEPLOYMENT

## Build Commands
```bash

npm run build    # tsc && vite build

```

## Production Build
- `vite build` outputs to `dist/`
- Assets: `dist/assets/index-*.js` (581KB, gz 152KB), `dist/index.html`, `dist/icons/*`, `dist/manifest.webmanifest`, `dist/sw.js`, `dist/workbox-*.js`, `dist/registerSW.js`
- No source maps for production (sourcemap false)

## Deployment Safety
Never assume works locally = works in production. Tested:
- Asset paths: relative, base `/`
- Routing: SPA, no router, single index.html
- Static resources: `/icons/*` from public
- Service worker: workbox precache 12 entries, scope `/`
- Manifest: PWA manifest.webmanifest generated by vite-plugin-pwa
- PWA scope `/`, start_url `/`, display standalone, orientation landscape, theme #0a0a0f
- Network endpoints: none currently (future backend separated)
- Environment config: no env vars needed, no secrets
- Never hardcode localhost, 127.0.0.1, dev URLs in production logic — checked, none
- No exposed secrets — no API keys, tokens

## PWA
- Manifest: name BLACK VEIL, short_name BLACK VEIL, description, theme_color #0a0a0f, background #050508, display standalone, orientation landscape, icons 192,512 maskable
- Service worker: generateSW, globPatterns **/*.{js,css,html,ico,png,svg,woff2,json}, runtimeCaching NetworkFirst for https://*
- Install flow: beforeinstallprompt captured, INSTALL GAME button shown, prompt on click, userChoice awaited
- Update strategy: registerType autoUpdate, safe cache versioning, avoid new JS + old assets crash via workbox precache versioning
- Offline strategy: app shell (index.html), menu, cached essential assets, local save — not full offline gameplay if network required, but core playable offline after first load

## Icons

- Located public/icons/, copied to dist via Vite public dir

## Known Production Considerations

- No multiplayer yet, architecture ready

- WebGL2 required, fallback message if not supported
